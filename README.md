# Наши рецепты — приложение

Семейная коллекция рецептов: ссылки на рецепты разбирает домашний компьютер (локальные модели),
а рецепты хранятся на телефоне и открываются без интернета.

Это только оболочка приложения (PWA). Данных и адресов здесь нет: телефон подключается к своему
домашнему компьютеру по одноразовому коду.
